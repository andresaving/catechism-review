# CateKids

Free games for kids to learn the **Westminster Shorter Catechism** (all 107
questions): Boss Battle, typing practice, Word Drop, Fill It In, Match Up,
Build It, Lightning Round, The Gauntlet (Q1 onward in order, word soup, three slips per answer, records per kid), Sibling Duel (two players on one iPad race to build the same answer, wrong tap freezes 2 s, first to 5), Flip It (answer → which question → which number), Spot the Swap and Say It. A slider limits every game
to the questions a child has studied so far.

No accounts, no ads, no tracking. Progress saves on the device. Works offline
after the first visit.

## Put it on a phone or iPad
Open the link in Safari (iPhone/iPad) or Chrome (Android) → Share →
**Add to Home Screen**. It opens full-screen with its own icon, like an app.
